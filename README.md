# 🔊 Noisemap IA — Previsão Inteligente de Ruído

## 🎯 Objetivo
Este projeto tem como objetivo prever níveis de ruído com base no horário, utilizando técnicas de Machine Learning integradas a uma aplicação web.

---

## 🧠 Inteligência Artificial

O sistema utiliza um modelo de Machine Learning do tipo **Regressão Linear**, treinado com dados históricos de ruído.

A IA é responsável por prever o nível de ruído com base na hora informada pelo usuário.

---

## ⚙️ Tecnologias Utilizadas

- Python
- Flask
- Pandas
- Scikit-learn

---

## 🔄 Fluxo do Sistema

Usuário → Interface Web → API Flask → Modelo de IA → Resultado

---

## 📊 Dados

Os dados utilizados foram simulados e representam níveis de ruído ao longo do dia.
